# Artisan Auctions user docs

Starlight Markdown pages. artisanmc.net copies this folder, at each release tag, under
`/docs/auctions/`. Links between pages are relative (`../configuration/settings/`).
`sidebar.yaml` names and orders the sidebar groups. Files starting with `_` are not pages.
Writing rules: https://github.com/artisanmc/website/blob/main/WRITING.md
